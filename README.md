# Pedra, Papel e Tesoura

Atividade Prática 1 – Desenvolvimento de Jogo Web. Um jogo digital iterativo de "Pedra, Papel e Tesoura" (Melhor de 3) desenvolvido inteiramente com as tecnologias base da web.

## Objetivo
Aplicar os conceitos estudados na disciplina, como estruturação de páginas (HTML), estilização visual (CSS), manipulação do DOM e lógica de programação (JavaScript) por meio de uma aplicação executada diretamente no navegador.

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript

## Regras do Jogo
1. O jogador escolhe entre Pedra, Papel ou Tesoura clicando nos botões.
2. O computador faz uma escolha aleatória.
3. Pedra amassa Tesoura; Tesoura corta Papel; Papel embrulha Pedra.
4. A cada rodada vencida, 1 ponto é adicionado ao placar do vencedor.
5. O jogo encerra quando um dos lados atingir 3 pontos.
6. Após o término, um botão para reiniciar a partida ficará disponível.

## Instalação e Execução
Não é necessária nenhuma instalação prévia ou servidor local.
1. Faça o clone deste repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em qualquer navegador web.
